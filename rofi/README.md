## Rofi Srcery theme

Rofi theme created to work with [Srcery colors](https://github.com/srcery-colors).

### Sample configuration

```rasi
@theme "~/path/to/srcery-gui/srcery_rofi.rasi"

configuration {
  font: "Iosevka 12px";
}

window {
  width: 25%;
  height: 100%;
}
```
